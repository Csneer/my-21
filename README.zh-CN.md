# my-21

**从世界的变化里，看见自己的下一步。**

[English](README.md) · [中文 Skill](skills/zh-CN/my-21/SKILL.md) · [English Skill](skills/en/my-21/SKILL.md)

21 个当天热点，21 天数字工作轨迹。让一个有能力的 agent 把它们放在一起，理解你正在走向哪里，发现接下来可能发生什么，以及哪些不同的下一步值得主动选择。

整个 skill 只有一页。它给 agent 一个观察与想象的视角，让探索随着发现展开。

## 它关心两种未来

| 顺着当前的方向 | 主动选择另一种可能 |
| --- | --- |
| 你接下来可能继续做什么？ | 今天的新变化，让什么事情变得值得做？ |
| 哪个投入正在形成新的方向？ | 哪项旧积累在新处境里有了用处？ |
| 哪个未完成的循环可能再次出现？ | 哪个过去的阻碍，现在有机会绕过？ |

也许是重新看一眼暂停的项目，也许是少做一次重复实现，也许是更有把握地继续原计划。输出可以是一段短笺、几个场景，或一项值得追索的发现，由内容决定形式。

## 一次可能的发现

下面是虚构示例，用来展示体验：

> 最近三周，你多次比较本地模型，但最近两次都决定先把工具交付出来。我猜你接下来会继续补齐导出和演示说明。
>
> 今天，上游库发布了结构化输出能力，可能正好帮助你保留摘要里的时间和原文位置。先确认它是否适配当前版本，再决定是否用它减少眼前的工作。
>
> 还有一个值得留下的东西：这次验证用到的困难日志样例，可以成为以后比较模型时的共同依据。你正在做的交付，也可能让下一次选型更容易。

好的发现有具体来处，也给你的判断和选择留下空间。

## 开始使用

选择一种语言。两版含义一致，技能名称都为 `my-21`。

| 语言 | 完整技能文件 |
| --- | --- |
| 中文 | [`skills/zh-CN/my-21/SKILL.md`](skills/zh-CN/my-21/SKILL.md) |
| English | [`skills/en/my-21/SKILL.md`](skills/en/my-21/SKILL.md) |

### 安装到 Codex

克隆公开仓库并复制中文版到用户技能目录，无需登录 GitHub：

```bash
git clone https://github.com/Csneer/my-21.git
cd my-21
mkdir -p ~/.agents/skills/my-21
cp skills/zh-CN/my-21/SKILL.md ~/.agents/skills/my-21/SKILL.md
```

这会安装或更新 `my-21`。如需英文版，将复制来源改为 `skills/en/my-21/SKILL.md`。两种语言选择一种即可。

Codex 会自动发现技能变更；若列表尚未更新，重新启动会话。其他支持 Agent Skills 的工具，可以按其安装方式导入所选的 `my-21` 文件夹。

### 给它一个真实的起点

在支持 `$` 技能调用的 Codex 界面中，可以这样开始：

```text
$my-21
结合今天的热点与我最近21天的工作，看看我接下来可能做什么，
以及有哪些原本没想到、值得考虑的方向。
```

也可以指定手头材料：

```text
$my-21
从我提供的项目笔记和任务记录开始，结合今天的新变化，
找一找哪些已经做过的事情，可能有了新的用途。
```

## 给 agent 什么材料

让它使用你愿意提供、且当前环境能够访问的项目、代码、对话、任务或日历。已有工作记录、选择性摘录和导出文件都可以成为起点；当天事件由 agent 使用可用的网页工具获取，或由你提供。

skill 本身不附带账号连接、历史采集或后台运行能力。材料不完整时，它应让判断保留相应的分寸。

个人工作记录请保存在仓库之外。分享结果或提交 Issue 前，先移除私密对话、凭据和他人的个人信息。

**21 是观察窗口。** 它不代表需要生成 21 个任务，也不是对个人未来预测能力的保证。

## 为什么只有一页

理解和探索应当互相推动：

> 带着对用户处境的理解探索世界，也让新发现反过来修正这份理解。

skill 保留观察对象、联想方向和好结果的标准。查什么、怎样追索、如何展开可能、用什么形式讲述，由 agent 根据这次材料决定。

更详细的依据见[设计说明（English）](docs/design.md)。
